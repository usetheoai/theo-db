# Milestone M160 — Decode zero-copy fixed-width → Arrow

## Outcome
Pushdown decode now decodes non-null fixed-width columns as one contiguous LE buffer (DecodedColumn::FixedRaw) → one
typed Vec<T> per column (PrimitiveArray::from), eliminating the per-cell Vec<u8> alloc storm + build_arrow re-read (the
M148-twin the deep-dive flamegraph found on the covered class). Measured same-binary (fast_decode off vs on, EXPLAIN
ANALYZE median-of-3, 1M ClickBench): 5.7×/7.4× grouped sum, 8.3× sum+count, 1.8× count-distinct (~2-8× covered
aggregations). A/B byte-identical (diverged=0) vs heap + unit test. Councils rust-pgrx + index-storage APPROVED (0
blocker/high/medium; LOW-1 comp_len guard fixed). Nullable/varlena/text/bool + pending rows keep the cell path
(fail-safe). GUC theodb.enable_columnar_fast_decode default ON. Released v0.151.0 (PR #203).
