# Milestone M157 — Rotear GROUP BY por expressão (date_trunc) ao CustomScan colunar

## Objective (from ROADMAP.md)

Rotear GROUP BY por EXPRESSÃO (`date_trunc`) ao CustomScan colunar vetorizado, subindo a cobertura ClickBench acima
de 31, byte-idêntico, com guards fail-closed.

## Definition of done (measured)

- [x] Cobertura `columnar_customscan_count` **31 → 32** (q42 `date_trunc('minute', EventTime)`) — head + systematic.
- [x] A/B byte-idêntico (`result_ab.diverged == 0`) nos dois regimes.
- [x] Guards fail-closed: `timestamptz`, `week`, **`month`/`quarter`/`year` (epoch mismatch)**, `EXTRACT`, `CASE`, aritmética declinam — provado por EC harness.
- [x] Semântica date_trunc casa PG (só granularidades epoch-invariantes {second,minute,hour,day}) — KEY-exact `mismatches=0`.
- [x] Serialização do group-expr (3º canal) — round-trip provado.
- [x] CHANGELOG.

## Outcome (written after MILESTONE_RELEASED)

CYCLE completo com rigor máximo. Discover (blueprint measurement-first: só q42 alcançável; HAVING/CASE/EXTRACT
honest-negatives com blocker independente) → plan+edge+confidence → implement (GroupExprSpec + admissão date_trunc + 3º
canal custom_private + group-expr DataFusion). Diagnóstico do decline via `THEODB_ADMIT_TRACE` (o admit aceitava; o
`deparse_safe_tlist` exigia FuncExpr onde pós-planning há Var). **Review pegou 3 defeitos, 1 CRÍTICO:** rust-pgrx 2 LOW
(fail-closed serialization); **index-storage CRITICAL** — o A/B inicial deu FALSO-VERDE (comparou count/sum, não a
chave) para `date_trunc('month'/'quarter'/'year')`, que diverge porque o storage colunar usa epoch µs-desde-2000 lido
pelo Arrow como µs-desde-1970 (offset 10957 dias, não-múltiplo de mês/ano → truncagem de calendário errada). Fix:
restringir a whitelist às granularidades epoch-invariantes {second,minute,hour,day}; q42 (minute) mantém a cobertura
+1. EC harness endurecido com A/B KEY-exact (symmetric-EXCEPT). Medido pós-fix: cobertura 32, diverged=0, day/hour/minute
`mismatches=0`, month/quarter/year/week/timestamptz declinam. Droplet da maratona reusado. Released v0.148.0 (PR #200, merge 3b9688b).
