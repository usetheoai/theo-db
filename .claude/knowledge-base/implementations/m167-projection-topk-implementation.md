**Rust edit → test recipe (one full turn ≈ 5 min):**

1. edit locally under `theodb_rs/src/`
2. `rsync -az --exclude 'target/' --exclude '.git/' theodb_rs/ root@165.227.121.20:/root/theo-db/theodb_rs/`
   — **NEVER `--delete`**: the droplet holds flattened copies of `theodb_rs/isolation/*` at the crate root that
   `--delete` would remove (67 files). Always dry-run with `--itemize-changes` first; without `-v` rsync prints
   nothing and silence does NOT mean "no differences".
3. rebuild remotely: `cargo pgrx install --release --features pg18 --pg-config /root/.pgrx/18.4/pgrx-install/bin/pg_config`
   (~4m15s with the warm release cache; run detached with `setsid nohup` so an SSH drop does not kill it)
4. restart PG so the new `.so` loads (`shared_preload_libraries = 'theodb_rs'`), then run the `EXPLAIN`/A/B step
5. **Python-only changes (T1.1) skip steps 3–4** — rsync `benchmarks/` and run directly.
