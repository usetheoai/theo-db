## Followups (obrigatórios para este verdict)

- **Exercitar o upgrade `1.4.0 → 1.5.0` de ponta a ponta.** O script foi gerado pela ferramenta e contém
  a correção (verificado por grep), mas **nenhum `ALTER EXTENSION theodb_rs UPDATE TO '1.5.0'` foi
  executado** neste ciclo. O projeto tem `scripts/test-upgrade.sh` para exatamente isso. Um upgrade
  incompleto sobe sem falhar e deixa o banco estruturalmente diferente de uma instalação limpa — é o modo
  de falha que o cabeçalho do próprio gerador descreve. **Este é o gap mais relevante do ciclo.**
- Medir a origem dos 29 s do teste do planner do `theo-rag` (o `B-020` mostrou que não é o `CREATE INDEX`).
