## Release notes

Fourth and final application of ADR-0050 (adopt-and-wrap) — completes the M127-M130 official-benchmark program
(vector / columnar / OLTP / HTAP).

- BenchBase (cmu-db, Apache-2.0) runs CH-benCHmark (TPC-C mix + 22 TPC-H-style analytical queries in one mixed
  phase) as an external out-of-tree Docker driver from a pinned SHA inside a Java-23 container — no source vendored.
- MEASURED across 3 sessions with **0% error**: mixed throughput mean 116.46 req/s (between-session CV 3.08%),
  derived dual metric proxy tpmC-proxy 2994.5 / QphH-proxy 5116.8 (labeled proxy, NOT audited TPC).
- Retained OLAP result-consistency oracle RAN LIVE — 22/22 CH queries PASS against TheoDB.
- Proves the mixed OLTP+OLAP wire-compatible gate end-to-end.

Honest finding recorded with its own artifact: SERIALIZABLE isolation exhausted SSI predicate-lock shared memory (a
documented PostgreSQL limitation, not a TheoDB defect) -> READ COMMITTED runs clean. Self-hosted shared droplet
(NOT canonical hardware); seed-determinism unconfirmed.
