## Release notes

### Added
- **(M20) Operadores de distância vetorial próprios em Rust — paridade numérica com pgvector (coexistência):**
  `theodb.l2_distance` / `theodb.inner_product` / `theodb.cosine_distance(vector, vector)` em Rust
  (`theodb_rs/src/vec.rs`), acumulação f32 byte-fiel ao `vector.c`, lendo os valores do pgvector via o cast
  lossless `vector::real[]` (coexistência — sem tipo competidor, sem clobber de operadores; índices/embed/
  hybrid/import intactos). Paridade provada (`benchmarks/tests/test_vector_ops.py`, ~1e-6 rel) + benchmark
  reprodutível. Sem nova dependência.
