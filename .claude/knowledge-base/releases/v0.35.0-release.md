## Shipped

- **Control-plane / platform removed — this repository is the database only.** Deleted the entire Go
  control-plane (`operator/`: k8s operator + CLI + gateway + MCP server + read-pool + observability) and
  the HA layer (`ha/`: Patroni + pgBackRest + failover/PITR smokes). Deploy, k8s orchestration, HA-via-operator
  and the platform surface are NOT part of the TheoDB engine — they belong to a separate layer. Accompanying
  cleanup: CI `ha-smoke` job removed; README stripped of operator/HA/deploy-tooling promises; ROADMAP
  M23/M24/M27/M28/M29 marked REMOVIDO (out of scope); CLAUDE.md "Integrating with the Theo platform" section
  removed; orphaned platform docs deleted (m23-operator-reconcile, m24-observability-readpool-mcp,
  ha-backup-runbook, conselho-tecnico-theodb).
  - **Preserved deliberately (honesty):** the DB engine (`theodb_rs`), `sql/`, `packaging/`, `benchmarks/`,
    and DB-technical docs (ADR/handbook/features/benchmarks). ADR 0006 (LOCKED Rust/Go strategy) left intact —
    its Go clause pending a formal superseding ADR (owner sign-off). Released CHANGELOG entries untouched (Rule 6).

## Scope statement

TheoDB is now, unambiguously, **the database**: a PostgreSQL-compatible engine (`theodb_rs`, a Rust pgrx
extension) + its packaging/benchmarks/docs. Control-plane, deployment, and platform integration are out of
this repository's scope.
