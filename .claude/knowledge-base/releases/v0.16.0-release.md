## Release notes

**M17 — `theodb.embed` rewritten in Rust (pgrx) at parity + benchmark** (ROADMAP-v2 / ADR 0006 foundation):

- **Added:** TheoDB's first own PostgreSQL extension in Rust, `theodb_rs` (pgrx 0.16.1) — establishes the
  "plpython3u → own Rust with parity + benchmark" pattern. Coexists with the SQL umbrella `theodb` (own
  schema `theodb_rs`; creates the public `theodb.embed` in the `theodb` schema, no clash).
- **Changed:** `theodb.embed` moved from plpython3u to Rust — SAME SQL contract (signature, GUCs, security:
  http(s)-only, no redirects/SSRF, REVOKE from PUBLIC). Parity proven by the 10-test oracle green against the
  image + byte-identical output vs plpython3u + identical typed errors (22023 input / 38000 endpoint). HTTP
  via `minreq` (ISC) with `https-native`/OpenSSL (avoids the rustls-webpki CVEs). Latency benchmark
  (`docs/benchmarks/m17-embed-rust-vs-plpython.md`): Rust 13.92 vs plpython3u 15.66 ms/call — no regression,
  I/O-bound, no perf claim.
- **Fixed:** `/plan-confidence` gate resolves citations under `.claude/knowledge-base/`.
