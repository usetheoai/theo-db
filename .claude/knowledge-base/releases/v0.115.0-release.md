## Release notes

Third application of ADR-0050 (adopt-and-wrap): pgbench + HammerDB TPROC-C as external out-of-tree drivers against
self-hosted TheoDB, with the retained wrap layer (run-to-run dispersion) + durability pairing.

- **pgbench** (PostgreSQL License, D1-clean): 3 sessions x 10 runs, TPS means 1247.3 / 1297.4 / 1328.3;
  within-session CV 7.6-9.5%, between-session CV 3.2%.
- **HammerDB TPROC-C** (real TPC-C 45/43/4/4/4 mix; GPLv3 external Docker driver, never vendored): NOPM = 18269
  (functional smoke, NOT audited tpmC).
- Durability server-reported (`SHOW fsync=on`); throughput paired with the retained crash-safety gate (#46/#47).
- Proves the 100%-wire-compatible OLTP gate end-to-end.

Honest: self-hosted shared droplet (NOT canonical hardware) -> functional baseline, not a competitive claim.
Review: 2 passes; 2 HIGH + 3 MEDIUM/LOW raised and all resolved (per-session artifacts; coefficient of variation
replacing a degenerate split-half significance test; server-reported durability).
Evidence: `docs/benchmarks/m129-oltp.md`.
