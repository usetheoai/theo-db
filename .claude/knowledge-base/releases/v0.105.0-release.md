## Release notes

### Added — Columnar `min(col)`/`max(col)` aggregate + zone-map directory fast-path

Admits `min`/`max` on ordered native types (int2/4/8, float4/8, timestamp/date) in the columnar CustomScan
byte-identical to PostgreSQL (output type = input column type). Adds a directory-only fast-path that answers a scalar
`min`/`max` with no WHERE by folding the zone-map `min_bits`/`max_bits` already written per (chunk_group, col) — never
decoding a column chunk.

**Measured (1M rows, c-8 droplet — `docs/benchmarks/columnar-minmax-zonemap-verdict.md`): GOAL MET** — integer/temporal
scalar min/max answer in **< 1 ms (~1300–1400× faster than the native scan)**, every shape byte-identical (as TEXT).
MVCC-correct (visible-stripe fold + same-xact pending, proven: uncommitted INSERT seen by max()); `max(float)` falls
back to the decoded scan (NaN correctness); GROUP BY / WHERE / empty / all-NULL byte-identical.

Scope: ordered native types (bool has no PG min/max aggregate; text/numeric deferred).
