## Release notes

### Added
- M31b — SIMD (AVX2+FMA) fused decode+distance for the `theodb_ivfflat` Index Scan hot loop: L2 distance computed
  directly from page bytes via `_mm256_loadu_ps`, cached `is_x86_feature_detected!` dispatch + scalar fallback.
  Measured on DISTINCT data: p50 **≤ pgvector** — 2.6× faster (uniform, recall parity) and 0.95× at recall 10/10
  (clustered). M31b DoD met. Evidence: `docs/benchmarks/m31b-simd-distance.{md,json}`.
- M31b — opt-in scan profiler (`THEODB_SCAN_PROFILE=1`): per-scan phase timing + list balance.

### Fixed
- Benchmark data-generation degeneracy (non-correlated `string_agg((random())…)` InitPlan → 100k identical vectors)
  that retro-invalidated M31's latency numbers. Fixed with Python `COPY` distinct seeding. No engine bug. ADR 0012.
