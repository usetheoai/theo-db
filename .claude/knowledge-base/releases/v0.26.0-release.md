## Release notes

### Added
- M26 — vector Index Access Methods `theodb_ivfflat` + `theodb_hnsw`: persisted Postgres index AMs that promote
  the in-memory rebuild-per-query ANN into real index engines (pgrx 0.16 IndexAmRoutine + GenericXLog page
  persistence). `CREATE INDEX … USING theodb_{ivfflat,hnsw}` builds once, persists to WAL-logged pages; ORDER BY
  `<->` LIMIT k → planner Index Scan at recall parity; incremental INSERT (pending buffer) / DELETE (MVCC recheck)
  / VACUUM (fold). ~16× faster than the rebuild-per-query function (86 ms vs 1372 ms on 5 000×128). Both AMs ship
  the l2 operator class; cosine/ip + partial-page-read optimization are documented follow-ups (ADR 0010).
