## Summary

M22 ships TheoDB's own **SBQ scalar quantizer** + quantized ANN search in Rust (`theodb.sbq_knn` /
`theodb.sbq_bytes_per_vector`), at **recall@k parity with pgvectorscale SBQ AND a measured memory profile**
(benchmark `PARITY_REACHED`, `docs/benchmarks/m22-sbq-parity.md`), in **coexistence** (reads `embed_col::real[]`;
pgvectorscale `diskann`/pgvector/M21/embed/hybrid/import untouched). Critical license finding: vectorchord/RaBitQ
is **AGPL-3.0** → study-only, NOT borrowed; the own SBQ is permissive std-only code (zero new dependencies).
Search = M21 IVFFlat carrier + Hamming (`popcount` XOR) + full-precision f32 rerank (M20 kernel). Memory is
**parity with pgvectorscale by identical formula + ~16-32× vs f32** (honest, not a win over it). 16 container
integration tests; clippy `-D warnings` clean; the quantizer's signal is independently proven.
