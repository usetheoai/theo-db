## What shipped

The complete own-code append-only columnar Table Access Method `theodb_columnar` (M99):

- **C1 — column-major TCS1 stripe encoding** + per-chunk min/max directory (FFI-free codec in `columnar_codec.rs`,
  12 local unit tests; FFI detoast/byval/varlena isolated in `columnar.rs`).
- **C2 — MVCC via the `columnar.stripe` heap catalog** (visibility delegated to Postgres), pre-commit flush,
  same-xact pending-in-memory read, DROP-table event-trigger cleanup.
- **D1 — 3 `pg_isolation_regress` MVCC permutations GREEN** (RR snapshot stability / abort-invisible / concurrent
  inserters non-overlapping).
- **D2 — crash-safety WAL-replay GREEN** (committed stripe survives immediate crash + replay, scan-identical) +
  honest columnar-vs-heap benchmark (9.2× on-disk compression; scan slower by design — vectorization is M100).

## Honest boundary

Append-only analytical only (UPDATE/DELETE/parallel/bitmap/sample are typed-error stubs). On-disk compression is the
measured win; projection + min/max skip-pruning **consumption** + vectorized scan speed land with M100 (the DataFusion
CustomScan). No performance-superiority claim (Rule 5 / M73/M97).
