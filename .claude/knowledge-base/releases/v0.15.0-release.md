## Scope

M16 makes the unification moat (ADR 0005) **demonstrable** — the step from "installable" (M15) to "product of
fact": the canonical unified query (vector `<=>` + relational `JOIN` + `WHERE` + `ai.*` in one transactional
SQL), recall-preserving filtered search (`hnsw.iterative_scan=strict_order` against over-filtering — proven by
test, not trivial), and a dependency-free Pinecone import (`theodb.import_pinecone`, native jsonb,
injection-safe, typed errors) + migration guide + an honest 1-vs-2-systems demo (simplicity/consistency, no
speed claim). The CTO's stated target was "M25"; clarified (via interview) as M16 — the unification derived
from ADR 0005.
