## What shipped

The heap-authoritative in-memory Arrow columnar cache (M101, HTAP), phases A-D:
- A — theodb_columnarize pragma builds an Arrow cache from a HEAP table via SPI; aggregate over it = heap.
- B — columnar.cache_state generation catalog + invalidate-on-write statement trigger + snapshot-correct rebuild (the MVCC substrate; generation read via MVCC → generation-read + rebuild co-snapshot).
- C — the M100 CustomScan admits a heap-with-usable-cache → vectorized aggregate in one plan.
- D — 2 pg_isolation MVCC permutations (cross-backend invalidation + RR snapshot stability, both GREEN) + HTAP benchmark (2.48x vs native heap).

## Measured evidence

- 303 pg_tests GREEN, zero regression. 2 isolation permutations GREEN. Benchmark: Arrow cache 52.4ms vs native heap 130.0ms = 2.48x.
