# Milestone M53 — Híbrida de verdade (WHERE + BM25 + BEIR)
## Objective (from ROADMAP.md)
Três dívidas da superfície híbrida: (a) FUSION_TEMPLATE não aceita filtro WHERE; (b) leg lexical é ts_rank_cd (BM25 mediu superior 0.9546 vs 0.5143 nDCG@10, não shipado); (c) o claim de recall da híbrida não tem artefato (BEIR real aberto desde 2026-06-28).
## Entry point (escopo mapeado)
DoD (4 itens, independentes):
1. **Filtro relacional na fusão** — `ai.hybrid_search_rrf(…, filter_sql)`; SECURITY INVOKER, confinamento sintático (rejeita `;`+comentários). Código: `theodb_rs/src/hybrid.rs` (FUSION_TEMPLATE_TSRANK/_BM25), `api.rs`.
2. **Gate de adoção BM25** — leg `pg_textsearch` (BM25) opt-in (`lexical_engine='bm25'`) + fallback `ts_rank_cd`; executa a exceção ADR 0013. Imagem `theodb:m53-bm25` (packaging/Dockerfile.m53-bm25).
3. **Benchmark BEIR real** — scifact (5183 docs/300 queries), OpenAI text-embedding-3-small → `docs/benchmarks/m53-hybrid-beir.{md,json}`.
4. **i18n** — idioma do to_tsvector/plainto_tsquery parametrizável.
Dependencies: M19 (híbrida existente), M50 (protocolo de medição).
## Outcome
**RELEASED v0.44.0** (PR #54 merged → main 74fbdbb; tag v0.44.0; GitHub release). Os 4 itens do DoD cumpridos com evidência:
- filter_sql + i18n (T1+T4) + leg BM25 opt-in (T2) — 6 pg_test hybrid verdes (accepts_filter_and_language, rejects_statement_terminator, rejects_sql_comment, bm25_without_text_col_errors, invalid_lexical_engine_errors, bm25_without_extension_raises_unsupported).
- Benchmark BEIR real (T3) — scifact 5183/300, 3 runs determinísticos: hybrid RRF **iguala** vector-only (recall@100 paridade 0.9733; edge +0.004 nDCG@10 marginal/não-conclusivo); BM25 (pg_textsearch) 0.6881 nDCG@10 ≈ vector, muito acima do ts_rank_cd 0.0703 → **gate de adoção ADR 0013 executado** (decisão: opt-in shipado no código; adoção como default na distribuição segue gated).
- Review: 3 council specialists (security/rust-pgrx/benchmark) → READY_TO_MERGE após fixes de honestidade (guard anti-comentário + doc do filter_sql corrigida como SQL cru caller-privilege; artefato benchmark sem over-claim de "SUPERA"/"9.8× ranker").
- Follow-ups rastreados no backlog: ADR de filtro estruturado fail-closed; teste de significância pareado; híbrida-com-bm25; pytrec_eval; nfcorpus.
