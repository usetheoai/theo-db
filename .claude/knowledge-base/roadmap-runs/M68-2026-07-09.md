# Milestone M68 — Observabilidade do query vetorial — EXPLAIN + métricas

## Objective (from ROADMAP.md)

Operabilidade: o scan vetorial é opaco; expor `EXPLAIN (ANALYZE)` com pages-read/recall-est
+ métricas runtime para o operador diagnosticar em produção.

## Definition of done (from ROADMAP.md) — todos [x]

- [x] `EXPLAIN` do scan vetorial mostra: índice, ef/probes efetivo, pages read, candidatos vistos
      — `theodb.explain_scan(...)`. Função diagnóstica separada (ADR-0027 D1 — não há `amexplain` no PG17/18).
- [x] Métricas runtime do scan (pilar (c) wiring-triad) — thread_local `SCAN_CANDIDATES` + catálogo heap
      `theodb._index_scan_stats` (`avg_candidates`). Catálogo consultável, não Prometheus (ADR-0027 D3, YAGNI).
- [x] Doc de operação — `docs/ops/vector-scan-diagnostics.md`.

## Outcome

M68 fecha o pilar P4 (operabilidade) do ROADMAP-v3 e, com ele, **todo o ROADMAP-v3 (M61–M68)**. A
observabilidade adiciona `candidates_seen` (o pool navegado no beam, capturado own-code em
`ground_search_nodes::visited.len()` e propagado ao thread_local irmão do `SCAN_PAGES_READ` do M67) —
o sinal que distingue "grafo caro de navegar" de "I/O pesado / spill", algo que pgvector/pgvectorscale
não expõem por-query. Superfícies: `theodb.explain_scan` (por-query), `theodb.scan_stats` (por-query +
persiste), `theodb.index_scan_stats` (agregado).

Validação (droplet DO c-8, pg17 real, stack completa pgvector + pgvectorscale + umbrella theodb):
6/6 pg_tests do módulo autotune GREEN (incl. os 2 novos `explain_scan_shows_index_and_candidates` e
`scan_stats_records_real_pages_read` estendido p/ 4-tupla + `sum_candidates>0`) + 13/13 pg_tests de
correção HNSW GREEN (recall preservado após a mudança de assinatura de `ground_search_nodes` que ripou
para 4 call-sites). Observabilidade → validado por teste determinístico, **sem benchmark de performance**
(nenhum claim "Nx"; Regra 5 não se aplica). Councils index-storage + rust-pgrx: READY_TO_MERGE, zero
BLOCKER/HIGH; findings LOW/INFO (honestidade documental) aplicados; 1 follow-up LOW pré-existente do M67
(quote_ident) registrado no backlog.
