# Milestone M166 — string aggregates + wide SUM(expr)

## Objective (from ROADMAP.md)

Pushdown coverage for the string-aggregate / wide-SUM ClickBench queries (q21, q22, q27, q29) that hold back the
overall geomean vs ClickHouse.

## Definition of done

- q29 (`SUM(int2 ± const)`) routes to the columnar-agg CustomScan, byte-identical A/B.
- Fail-closed: int4-base / int8-result / out-of-range decline.
- q21/q22 (`MIN(text)`) documented as collation honest-negatives; q27 (`AVG(length)`) deferred.
- Benchmark evidence + CHANGELOG; type-coverage A/B extended.

## Outcome (in progress)

Discovery ranked q29 as the one clean, safe win (`SUM(int2 ± const)` provably overflow-free); q21/q22 correct
collation honest-negatives (byte-min ≠ collation-min); q27 deferred (new scalar-func-in-agg mechanism + UTF-8 gate).

Implemented (commit db7040c): `AggSpec::SumIntAddConst` (kind 9), fail-closed to int2-base + int4-result, delta
hi/lo-encoded, deparse OUTER_VAR fix. Measured (1M ClickBench, same-box vs ClickHouse 26.8.1): **q29 567.13× → ≈2.10×**
(same-engine 27.79 s → 0.1027 s, ≈270×), 43/43 A/B byte-identical (0 regressions), type-coverage A/B **31/31** (fail-closed
cases proven), `EXPLAIN VERBOSE` no-crash.

Pending: council-rust-pgrx + council-benchmark sign-off, `/release` v0.157.0, checkbox flip.
