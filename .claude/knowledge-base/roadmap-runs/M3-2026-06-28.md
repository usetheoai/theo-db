# Milestone M3 — Migração mínima

## Objective (from ROADMAP.md)

Caminho de entrada a partir do PostgreSQL vanilla via import/export padrão.

## Definition of done (state at flip)

- [x] Import/export padrão (`pg_dump`/`pg_restore`) documentado e testado contra um Postgres vanilla —
  `docs/migration/minimal-migration.md` + `migrate-smoke.sh` + job CI `migration-smoke` (verde).
- [x] Migração de banco vanilla com tabela vetorial preserva dados e índices num smoke — checksum de
  linha-inteira idêntico source↔target + definições dos 4 índices preservadas + HNSW/IVFFlat usáveis;
  `migrate-smoke-selftest.sh` prova que o assert não é teatro.
- [x] Guia de migração mínima publicado — `docs/migration/minimal-migration.md`; consistência guia↔smoke
  garantida por `migrate-doc-check.sh`.

## Outcome

M3 entregue end-to-end e released em **v0.3.0** (PR #4, merge `fe9a735`, tag `v0.3.0`, GitHub release).
Caminho padrão `pg_dump`/`pg_restore` (Regra 9, sem ferramenta própria), provado empiricamente e em CI.
Review READY_TO_MERGE (0 BLOCKER; HIGH resolvidos na raiz: fail-fast no restore, checksum de linha-inteira,
índices por definição, IVFFlat usável). CI verde (run `28319401284`, incl. `migration-smoke`) confirma o
DoD-1 "testado em CI".

A release v0.3.0 também trouxe um **fix** (não-M3): `theodb.embed` alcança provedores HTTPS de nuvem
(`ca-certificates`), validado contra a API real da OpenAI (`vector(1536)`).

- Escopo single-table; Option B (plain) documentado+verificado mas não executado separadamente pelo smoke.
