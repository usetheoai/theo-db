# Milestone M115 — Composabilidade do M100: saída columnar-agg usável em subquery/join

## Objective (from ROADMAP.md)

Resolver a limitação pré-existente do M100 onde consumir o VALOR de saída de um agregado colunar dentro de uma
expressão externa (subquery/join/ORDER-BY-de-agregado) falha com `cache lookup failed for attribute N of relation 0`.

## Definition of done (from ROADMAP.md)

(1) diagnóstico do caminho setrefs/SubqueryScan-removal; (2) fix que torne a saída consumível; (3) saída escalar E
agrupada usável em subquery/join/ORDER-BY; (4) A/B/testes byte-idênticos; (5) sem regressão do top-level. All met.

## Outcome

Full CYCLE: discover (Staff blueprint — PG setrefs.c/nodeCustom.c + Citus + TimescaleDB primary sources) → plan
(SHIPPABLE_WITH_CAVEATS) → implement (droplet; THREE empirically-disproven CustomPath-level attempts before the
correct Agg-swap rearchitecture — TimescaleDB vector_agg pattern) → code-quality → review (council-rust-pgrx found +
fixed 4 real blockers: parallel partial-swap, ORDER BY DESC, same-OID cross-match, planner-longjmp safety) → release
v0.103.0 (self-merged PR #123). VERDICT: GOAL MET — the four previously-failing shapes byte-identical + CustomScan;
DESC + parallel byte-identical; no regression (M114 aggregate breadth, GROUP BY pushdown, top-level all still columnar
+ byte-identical). Evidence: docs/benchmarks/m115-columnar-composability-verdict.{md,json}.
