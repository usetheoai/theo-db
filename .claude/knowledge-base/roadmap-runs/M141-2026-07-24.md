## O que foi genuinamente entregue nesta linha de trabalho

O CYCLE executado em 2026-07-24 mudou o diagnóstico do milestone: ele **não estava bloqueado apenas por
tempo humano**. Ao tentar apontar uma capability theo-data real (`theo-memory`) para o TheoDB, descobriu-se
que **nenhuma conseguia sequer inicializar**:

- **#181 (corrigido, released v0.137.0)** — `CREATE EXTENSION IF NOT EXISTS vector` falhava. Shim `vector`
  + dependência em `template1`; ADR-0058; harness `pgvector_compat_check.sh` com chamador `make
  check-compat` e não-vacuidade provada; review de 2 agentes (READY_TO_MERGE, 0 BLOCKER) que pegou um
  falso-verde (o tooling real emite `CREATE EXTENSION` **sem** `CASCADE`).
- **#182 (aberto)** — a migration versionada real do `theo-memory` avançou da linha 6 para a **linha 44** e
  quebra em `CREATE INDEX ... USING hnsw (col vector_cosine_ops)`. Mapeamento 1:1 já medido.
- **#183, #184** — derivados do review de segurança.
