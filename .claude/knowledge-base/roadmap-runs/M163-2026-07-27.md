# Milestone M163 — Harness A/B por-tipo

## Objective (from ROADMAP.md)

Fecha o gap recorrente "A/B passa, review acha o bug de classe-de-tipo" — um harness A/B por-tipo que roda ANTES do
`/review` e pega regressões de classe-de-tipo (int widening, temporal, float IEEE, colação) que os dados do ClickBench
não exercitam.

## Outcome

Shipped in v0.154.0. The harness (`benchmarks/columnar_type_ab.py`) asserts the M161 fail-closed contract per routed
admit-path × per-type edge value, with routing evidence and byte-identity comparison drawn from the same execution
(`EXPLAIN ANALYZE CREATE TEMP TABLE`). It earned its keep on the first live run by finding a real float `GROUP BY`
divergence (IEEE −0.0≠+0.0 vs `float8eq`), fixed by declining float group keys in `classify_target_node`. Two council
reviewers (rust-pgrx + benchmark) — the benchmark HIGH (routing measured on a different query than the divergence) was
fixed and re-validated live: 20/20 cases as-expected, positive control diverged=2, exit 0. Wired as a pre-`/review` gate
in `rules/testing.md § 5.1`.
