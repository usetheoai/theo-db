# Milestone M2 — Vetorial / IA (pilar killer) — MVP

## Objective (from ROADMAP.md)

Provar superioridade vetorial com evidência (ADR 0002, measurement-first): harness recall@k/latência
reproduzível (gate), medir baseline pgvector/pgvectorscale, decidir o índice pela evidência, + geração
de embeddings via SQL sobre modelo configurável.

## Definition of done (state at flip)

- [x] **DoD-1** — Harness recall@k/latência/QPS/build/memória reproduzível **rodando em CI** sobre dataset
  de referência ANN-Benchmarks (`glove-25-angular`), publicado em `docs/benchmarks/`. CI verde
  (run `28293702614`, job `image-and-bench` executa o harness-gate sobre o glove real).
- [x] **DoD-2** — Índice além do HNSW disponível (pgvectorscale StreamingDiskANN), **escolhido pela
  evidência**: HNSW default (glove-25 real: HNSW domina todos os eixos). Superioridade ScaNN-class
  `UNBENCHMARKED` (alta-dim/escala — follow-up).
- [x] **DoD-3** — Função SQL `theodb.embed()` de modelo configurável (endpoint OpenAI-compatible;
  padrão AlloyDB; `tools/embedding_server.py` modelo local real).
- [x] **DoD-4** — Política de Fork (D3) honrada: pgvectorscale as-is, commit `57c88b7`, sem fork.
