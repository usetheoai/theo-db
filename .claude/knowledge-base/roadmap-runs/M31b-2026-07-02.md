# Milestone M31b — Distância vetorial SIMD (AVX2 + runtime dispatch)

## Objective (from ROADMAP.md)

Fechar o gap de latência vs pgvector com distância vetorial SIMD (AVX2+FMA + runtime dispatch), preservando recall.

## Definition of done (from ROADMAP.md)

theodb_ivfflat Index Scan p50 ≤ pgvector (n≥100k, dim=128), recall preservado, sem novas dependências.

## Outcome

RELEASED as v0.28.0. DoD met on DISTINCT data: theodb p50 ≤ pgvector in both regimes (uniform 0.38× at recall
parity; clustered 0.95× at recall 10/10). The measurement-first profiler exposed a benchmark-data degeneracy
(100k identical vectors) that had retro-invalidated M31's latency numbers — fixed (ADR 0012), no engine bug.
