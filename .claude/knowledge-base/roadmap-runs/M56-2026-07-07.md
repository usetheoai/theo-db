# Milestone M56 — Manutenção in-place (tombstone) — remove o muro do VACUUM (ADR 0017 fase 1)
## Objective (from ROADMAP.md)
Implementa a fase 1 do ADR 0017: DELETE vira tombstone in-place por página (à la pgvectorscale/pgvector), removendo o rebuild O(N) sob EXCLUSIVE do caminho de delete. Compaction via fold M48 por threshold. Teto de memória do BUILD. Pré-requisito de v1.0 E de medir o P0 (M57) a 1M.
## DoD (6 itens)
1. DELETE tombstone in-place por página (element-tuple deleted+version), sem O(N)-RAM, sem EXCLUSIVE index-wide; reúso de slot no aminsert; scan filtra tombstones.
2. Recall preservado sob tombstones; medir recall entre compactions (decide fase 2 RepairGraph).
3. Compaction por threshold reusa fold.rs (M48), crash-safe.
4. Teto de memória do BUILD (collect_corpus streaming/batched).
5. Benchmark: parada do DELETE-path << 86s + RAM O(#deletados) -> docs/benchmarks/m56-inplace-maintenance.{md,json} vs baseline M55.
6. Layout Changed (magic bump + REINDEX); crash-injection e2e.
Deps: M55 (ADR 0017), M48 (fold.rs). Risco ALTO (imutabilidade M35 no delete path, version machine, FFI VACUUM in-place).
