# Milestone M7 — IA avançada

## Objective (from ROADMAP.md)

Filtered vector search, hybrid search + reranking, NL → SQL seguro (views parametrizadas) e funções de IA
generativa em SQL (geração de texto, classificação condicional, análise de sentimento, sumarização) sobre
modelo configurável local/remoto.

## Definition of done (from ROADMAP.md) — all met

- [x] Hybrid search (texto + semântico) + reranking (RRF) com recall medido — **S1** (`ai.hybrid_search_rrf`, BEIR-style recall harness; v0.6.0).
- [x] NL → SQL com guarda contra prompt-injection (views parametrizadas seguras) — **S4** (`ai.nl_to_sql`/`ai.nl_query`, 4-layer defense: prompt + static validation + native read-only sandbox 25006 + parser-grade EXPLAIN relation allowlist; v0.7.0).
- [x] Alternativa permissiva a BM25 full-text identificada (pg_search AGPL barred) — **S2** (`timescale/pg_textsearch`, PostgreSQL License, identified + functionally proven + measured vs ts_rank_cd; v0.7.0).
- [x] Funções de IA generativa em SQL (`ai.generate`/`ai.if`/`ai.analyze_sentiment`/`ai.summarize`/`ai.rank`) sobre modelo configurável, com teste de contrato por função — **S3** (model-agnostic over a configurable chat endpoint; 12 offline + real-OpenAI tests; v0.7.0).

> Filtered vector search (DoD-1) and weighted/array-cursor "accelerated" modes are documented follow-ups
> (YAGNI), not blockers for the M7 DoDs above — the hybrid/RRF + generative + NL→SQL + permissive-BM25 set is
> complete and evidence-backed.

## Outcome

M7 (IA avançada) delivered as four reviewed slices, each reaching READY_TO_MERGE with functional evidence:

- **S1 — hybrid search FTS+vector+RRF** (v0.6.0): `ai.hybrid_search_rrf` (RRF k=60, injection-safe, least-privilege) + BEIR-style recall harness with measured numbers.
- **S2 — permissive BM25** (v0.7.0): pg_textsearch (PostgreSQL License) identified, reproducible license sweep (VectorChord-bm25 = AGPL barred), functional build + measured recall (BM25 nDCG@10 0.9546 vs ts_rank_cd 0.5143). Measurement-first: distribution-adoption gated on a real-corpus benchmark; BM25F deferred (ADR 0003 §D4).
- **S3 — generative ai.* functions** (v0.7.0): 5 scalar functions over a configurable OpenAI-compatible endpoint (model-agnostic — the lever over AlloyDB's Gemini lock-in); single `ai._chat` HTTP source of truth; real-OpenAI verified.
- **S4 — safe NL→SQL** (v0.7.0): `ai.nl_to_sql`/`ai.nl_query` with a never-trust-the-LLM 4-layer defense; 2 read-exfil BLOCKERs found in review and fixed with a parser-grade EXPLAIN allowlist; read-exfil + write both deterministically blocked; real-OpenAI verified.
