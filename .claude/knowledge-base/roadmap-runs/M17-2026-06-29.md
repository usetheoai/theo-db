# Milestone M17 — Fundação: extensão própria `theodb` em Rust (pgrx) + 1ª feature com paridade

## Objective (from ROADMAP-v2.md)

Stand up TheoDB's own PostgreSQL extension in Rust (pgrx) and rewrite the first feature (`theodb.embed`)
from plpython3u to Rust with proven parity + a benchmark — the foundation of ROADMAP-v2 / ADR 0006.

## Outcome

Delivered in v0.16.0 (PR #17, merge commit `6a6c8d8`, tag `v0.16.0`). `theodb.embed` rewritten in the own
Rust extension `theodb_rs` (pgrx 0.16.1, minreq https-native), at proven functional parity (the 10-test
Python oracle green against the real image + byte-identical output vs plpython3u + identical typed SQLSTATEs
22023/38000) and with a reproducible latency benchmark (Rust 13.92 vs plpython3u 15.66 ms/call, I/O-bound, no
perf claim). Coexistence with the SQL umbrella `theodb` solved (own schema `theodb_rs`; `theodb.embed`
installed into the `theodb` schema). Review READY_TO_MERGE (3 agents, 0 BLOCKER/HIGH).

**Note:** M17 lives in `ROADMAP-v2.md` (the active V2 north star), not `ROADMAP.md`; the `cycle-release`
flip script targets `ROADMAP.md`, so the checkbox was flipped manually here (honest tooling limitation).
