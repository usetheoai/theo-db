# Milestone M74 — (CONDICIONAL) Quantização SOTA no índice — lever viável não-refutado

## Outcome

O gate condicional do M74 (só arranca com lever não-refutado + evidência de viabilidade). Lever identificado e
MEDIDO = **RaBitQ** (arXiv:2405.12497, 1-bit, training-free, bound de erro provado; core vendorizado ADR-0032;
spike D3 1M×768d). **Veredito honesto (ADR-0036):** o lever É viável e não-refutado, mas o ganho medido é
**MEMÓRIA/billion-scale** (5.3 MB residentes @ 98.4% na variante disk, 32× compressão), **NÃO superioridade de
QPS** (MSTG-RaBitQ-mem 8.2 ms @ 98.4% = competitivo com full-precision ~10-15 ms, não os 25× do ScaNN).

**Decisão (anti-sunk-cost/D3):** NÃO implementar o AM IVF-RaBitQ completo agora perseguindo QPS-superioridade (a
medição mostra que esse ganho não existe no regime 768d). Manter o core vendorizado como fundação de uma feature
futura de memória/escala, gated por demanda real de billion-scale. O veredito M73 (superioridade de QPS
não-alcançável por extensão PG permissiva) é o estado final do pilar.

**ROADMAP v5 (pilar vetorial P0) COMPLETO** com este release (v0.66.0). Reposicionamento formal do North Star
(ADR-0033) permanece decisão do owner.
